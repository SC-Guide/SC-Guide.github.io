About the Project

Skincare Guide is a personal routine planner that helps users track their daily skincare steps, manage product inventory, and visualize their schedule with an interactive calendar. The project is fully bilingual (EN/RU) and supports dark/light themes.

Key Features

Smart Routine Planner

Automated scheduling of retinal and azelaic acid based on your personal start date. Visual step‑by‑step morning and evening routines.

🔹 Algorithm: day‑based alternating active ingredients

Search & Filter

Real‑time search by product name, description, or ingredients. Filter by “recommended only” and “my products”.

🔹 Live filtering with zero dependencies

Product Library

Curated product database with prices, ingredients, usage instructions, and direct shop links (Boots, Amazon, etc.).

🔹 40+ products with multilingual support

Dark / Light Theme

Seamless theme switching with system preference detection. All CSS variables for easy customization.

🔹 CSS custom properties, prefers‑color‑scheme

Bilingual Interface

Full support for English and Russian. All UI texts, product data, and comments are stored in a single translation object.

🔹 i18n with simple key‑value mapping

Interactive Calendar

Snake‑style calendar with day‑by‑day routine preview, done/undo marks, and automatic retinal/azelaic scheduling.

🔹 Pure CSS/JS, responsive, localStorage persistence

Design System

A cohesive color palette with semantic tokens ensures consistency and accessibility.

🚀 Future Roadmap

Planned enhancements to scale the project and improve user experience:

  • Full Firestore integration – replace localStorage with cloud database, enable multi‑device sync
  • User‑generated product reviews and ratings
  • AI‑based product recommendations based on skin profile
  • Progress analytics – track consistency and improvement over time
  • Progressive Web App (PWA) – offline support and installable
  • Integration with external APIs (e.g., Skincare ingredient checkers)
  • Admin panel for managing product database
